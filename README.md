# Minha Carreira | N7sistem

Painel web para organizar candidaturas e atalhos de portais de vagas.

## Publicação no GitHub Pages
Envie `index.html` e `404.html` para a raiz do repositório. Em **Settings > Pages**, publique a branch principal pela pasta `/root`.

## Dados
Candidaturas e portais personalizados são armazenados no navegador do usuário. Não há banco de dados ou sincronização automática.
